# ClipCart · TikTok 东南亚带货视频工作台

共享版入口：`python team.py`，创建账号与部署流程见 [团队说明](docs/team.md)。

本地剪辑能力：上传商品图片/视频 → 编写多语言脚本 → FFmpeg 竖屏裁切与拼接 → 下载 MP4。

## 启动

需要 Python 3.10+、FFmpeg（含 libx264）。无需 Python 第三方依赖。

```bash
cd /workspace/111
python server.py
```

服务默认监听 127.0.0.1:8000。使用现有仓库开发，无需另建 worktree。生成素材与导出文件保存在忽略目录 `.runtime/`。服务仅供本地单用户使用，无登录、队列持久化或生产部署保障；进程重启后任务状态清空，输出文件保留。

## AI 配置

在安全的运行环境中设置 `OPENAI_API_KEY`，可选 `OPENAI_MODEL`（默认 gpt-4o-mini），随后重启服务。不要将密钥写入仓库或聊天。请求发送至 api.openai.com；所选环境需允许该域名。未配置时使用明确标记的模板草稿，不会调用模型。

支持印尼语、泰语、越南语、马来语、菲律宾语、英语、中文的 AI 脚本指令；实际翻译质量需要人工审核。

## 当前边界

- 真正执行素材上传、按上传顺序裁切拼接、15/30/45 秒目标时长、720×1280、30fps、H.264 MP4 导出。
- 视频素材短于分配片段时长时，不会自动循环补齐，最终时长可能较短。
- 可上传 MP3/WAV/M4A/OGG 背景音乐并试听、调整音量、移除；短音乐循环，长音乐截取，结尾淡出。素材原声不保留；未添加 BGM 时输出无声。脚本仅供参考，不自动生成配音或烧录字幕。
- 暂无 AI 视频生成、智能镜头评分、数字人口播、TikTok 登录或自动发布。
- 上传文件建议单个小于 40MB，最多 12 个。画面采用居中裁切，请检查商品是否被裁掉。
- 使用自己拥有授权的商品素材；发布前复核商品描述、平台标识及音乐授权。

开源技能调研见 [docs/skills.md](docs/skills.md)。

## 在电脑上添加 BGM

启动服务并打开工作台，在“背景音乐 BGM”中选择电脑上的音乐文件，点击播放器试听，拖动音量滑杆（默认 30%），再点击“开始自动剪辑”。音乐会编码为 AAC 并写入 MP4，下载后即可播放。修改音乐或音量后需要重新生成成片；选择“移除音乐”后重新生成即可导出无声视频。请使用有相应商用授权的音乐。

## TikTok 官方选曲入口（默认）

在“背景音乐 BGM”中，默认选择“TikTok 商用音乐库 · 发布时添加”。点击按钮会在新标签页打开官方曲库：
https://www.tiktok.com/business/en/commercial-music-library

按目标市场、账号及使用场景核对曲目，记录曲名与作者。工作台在此模式导出无 BGM 视频，即使此前上传过本地音乐也不会应用。将视频上传 TikTok 后，在发布流程中找到并添加选定曲目，调整片段与音量；能否使用以平台当时显示的授权为准。该入口不提供自动下载、官方音乐烧录或授权保证。

如需合成本地授权音乐，切换为“本地授权音乐 · 合成到 MP4”。切换设置后需重新生成成片，已有导出文件不变。
